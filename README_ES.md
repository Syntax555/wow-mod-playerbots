# Playerbots: integración portátil

Esta rama forma parte de
[AzerothCore Playerbots Portable](https://github.com/Syntax555/mod-playerbots-portable).
El [README en inglés de esta rama](README.md) describe la instalación,
configuración, límites, desarrollo y licencias actuales. Para jugar, descarga
el servidor y el paquete de cliente EraTalents correspondiente desde
[Latest](https://github.com/Syntax555/mod-playerbots-portable/releases/latest).
Para compilar, usa las revisiones exactas del núcleo y los módulos indicadas en
[versions.lock.json](https://github.com/Syntax555/mod-playerbots-portable/blob/main/versions.lock.json).

El [README original importado](https://github.com/buildthehomelab/wow-mod-playerbots/blob/5283a13e0a5d873350fdaef777b95d553d354bee/README.md)
se conserva como referencia del proyecto de origen; sus instrucciones generales
no sustituyen las de esta distribución.
