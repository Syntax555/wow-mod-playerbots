# Playerbots：便携版集成

此分支用于 [AzerothCore Playerbots Portable](https://github.com/Syntax555/mod-playerbots-portable)。
当前安装、配置、功能限制、开发分支与许可证说明以[本分支英文 README](README.md)为准。
普通用户请从便携版的 [Latest 发布](https://github.com/Syntax555/mod-playerbots-portable/releases/latest)
下载服务器和配套 EraTalents 客户端包。源码构建必须使用便携版
[versions.lock.json](https://github.com/Syntax555/mod-playerbots-portable/blob/main/versions.lock.json)
指定的核心及模块提交。

[导入版本的上游中文说明](https://github.com/buildthehomelab/wow-mod-playerbots/blob/5283a13e0a5d873350fdaef777b95d553d354bee/README_CN.md)
